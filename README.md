## Aim

To study Software Configuration Management (SCM) using Git and GitHub, and apply repository creation, commits, branching, merging, tagging, and version-history inspection to EEWMS project documents.

## What this repository demonstrates

- A `Version1` baseline branch and annotated `v1.0` tag.
- Change Request CR-01 developed on `feature/privacy-aware-trends`.
- A merge back into `Version1` and annotated `v2.0` release tag.
- Configuration-item tracking, change history, and comparisons between revisions.
